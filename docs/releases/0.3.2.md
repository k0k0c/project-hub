# Project Hub 0.3.2 — Pre-alpha 1

Первый публичный тестовый выпуск Project Hub для Windows 10/11 x64.
Это pre-alpha: функции и интерфейс могут меняться, возможны ошибки.

## Что можно попробовать

- Проекты, задачи, этапы, отчёты и история работы.
- Подключение агентов через MCP для чтения контекста и работы с задачами.
- Документация, исследование исходников и представления структуры проекта.
- Экспериментальное управление чатами Codex через отдельный адаптер.
- Прямые запросы из Hub к моделям через аккаунт ChatGPT или API-ключ сервиса.
- Резервное копирование и восстановление данных Hub.

## Установка

Скачайте `ProjectHub-0.3.2.exe` из файлов этого выпуска и запустите установщик.
Python включён в комплект; устанавливать его отдельно не требуется.
После установки откройте Project Hub через ярлык: интерфейс появится в браузере.

Контрольные суммы находятся в `SHA256SUMS.txt`, сведения о составе установщика —
в `ProjectHub-0.3.2.manifest.json`.

## Ограничения

Управление чатами подготовлено только для Codex и требует отдельной настройки.
Подключение MCP не включает управление приложением автоматически.
Совместимость MCP зависит от возможностей клиента.

Подключения к моделям экспериментальные. Вход через аккаунт реализован для
ChatGPT; API-подключения поддерживают протоколы OpenAI, Anthropic, Google Gemini
и совместимых Chat Completions-сервисов. Доступность конкретной модели нужно
проверить с вашим аккаунтом или ключом. Запросы могут расходовать лимиты сервиса.

Данные Hub хранятся локально. При запросах к внешним моделям необходимые
материалы, включая фрагменты кода, передаются выбранному сервису.
Перед важной работой сохраняйте резервную копию данных.
